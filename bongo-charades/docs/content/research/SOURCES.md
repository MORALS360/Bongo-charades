# Bongo Charades — Source Registry

One numbered entry per source. Evidence files refer to sources by number, for example `[S1]`.
All sources were accessed on **2026-11-13** unless stated.

**How to read the "Read?" column**
- **Full** — I opened the page and read the relevant content.
- **Part** — I opened the page but only extracted specific facts from it.
- **Summary only** — I saw the source in a search-result summary and did not open it. Facts from these are treated as leads, not evidence, until the page is opened.

**Confidence** follows the Phase 5 strategy: High · Medium · Needs local verification.
